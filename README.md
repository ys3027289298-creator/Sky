# 星陨防线

《星陨防线》是一个可直接在浏览器运行的原创 3D 太空射击游戏，使用 TypeScript、Vite、Three.js 和 Vitest 开发。玩家驾驶轻型战斗飞船，在废弃采矿区、失控空间站和敌方舰队外围完成连续任务，管理燃料、弹药、护盾、装甲、能量、维修材料与改装取舍。

## 启动

```powershell
npm install
npm run dev
```

打开终端中显示的本地地址，通常是 `http://localhost:5173/`。无需注册、登录或后端服务。

生产构建：

```powershell
npm run build
npm run preview
```

## 测试

```powershell
npm test
```

测试覆盖：

- 飞船推进、惯性、加速限制、碰撞伤害
- 武器射速、弹药、过热、冷却和命中统计
- 导弹锁定、遮挡脱锁、目标切换
- 护盾、装甲、部位损伤与维修
- 敌人巡逻、发现、追击、攻击、撤退和死亡
- 四个任务的开始、完成、失败和撤离
- 资源拾取、三级改装、localStorage 存档
- 六种动态事件和指挥舰护盾/弱点战斗

## 推荐 10–15 分钟录屏路线

1. 主菜单选择“简单练习”或“完整流程”，第一关飞入左前方废弃采矿区。
2. 靠近扫描区域按 `F`，展示无人机、陨石碰撞和撤离点。
3. 完成第一关后回到主菜单，进入“飞船改装”，升级引擎、护盾或武器。
4. 开始后续任务，途中展示左键主炮过热、右键导弹锁定、补给拾取和维修。
5. 空间站任务摧毁三个防御节点、取得核心，在倒计时结束前撤出。
6. 最终任务关闭两座干扰塔，再攻击指挥舰弱点，最后穿过舰队火力撤离。
7. 可主动撞击陨石或不恢复护盾录制失败页；失败原因会明确显示。

## 任务

1. **废弃采矿区侦察**：进入采矿区、扫描目标、躲避无人机并返航。
2. **陨石带护航**：与运输船路线会合，消灭截击力量，运输船生命归零则失败。
3. **失控空间站突袭**：摧毁三个防御节点，取得能源核心，在爆炸倒计时前撤离。
4. **舰队外围终战**：关闭两座干扰塔，击破带护盾和弱点的指挥舰，在合围前撤离。

## 武器与防御

- **双联能量炮**：均衡主炮，持续射击会过热。
- **高速脉冲炮**：高射速、短射程，适合截击机。
- **追踪导弹**：需要锁定，有限弹药，可被遮挡和距离影响。
- **范围爆破弹**：慢速高伤，适合重型目标和集群。

飞船拥有生命、护盾、装甲、能量、燃料和部位耐久。护盾优先承伤并在脱战后恢复；装甲和引擎、武器、雷达损伤不会完全自愈，需要寻找维修信标或消耗维修包。

## 动态事件

游戏包含陨石带偏移、敌人增援、护盾故障、能源站爆炸、运输船改线和空间风暴。事件有倒计时提示，并实际改变增援、航线、能见度、护盾恢复、能量消耗或战斗压力。

## 存档和改装

游戏使用浏览器 `localStorage` 保存：

- 已解锁任务
- 资源和改装点
- 六类装备的三级升级
- 鼠标灵敏度和音量
- 任务战绩历史（见下节）

改装不是纯数字：引擎影响速度和冲刺，护盾影响护盾量和回复，装甲影响减伤，武器影响伤害和射速，雷达影响锁定距离，导弹舱增加副武器弹药。

## 任务战绩

每次任务成功或失败结算时自动生成一条 `RunRecord`，与存档共用一个 localStorage 主键（`starfall-defense-save`），存放在 `SaveData.history` 中。主菜单点击“任务战绩”即可回顾。

每条记录包含：

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定唯一的 run 标识，重复写入幂等 |
| `missionIndex` / `missionName` | 任务序号与名称 |
| `success` / `reason` | 成功或失败、结算文案/失败原因 |
| `startedAt` / `finishedAt` / `duration` | 开始、结束时间戳与用时（秒） |
| `kills` / `shots` / `hits` / `accuracy` | 击毁数、射击数、命中数、命中率 |
| `reward` | 当局结算资源 |
| `upgrades` | 结算时的六级改装快照（深拷贝） |

记录只保存摘要，不包含敌人、位置数组、Three.js 对象或输入事件。

兼容策略：

- 旧版存档（只有 `unlockedMission/resources/points/upgrades/settings`）按空历史读取，升级后自动写入 `schemaVersion`。
- 坏 JSON、`history` 非数组、字段缺失、非法数字、未知状态都会降级为空历史或安全默认值，不会覆盖已有的解锁、资源、改装和设置。
- 追加记录前先规范化，再按 `finishedAt` 倒序保留最近 20 条；同一 `id` 重复写入只保留一条。

界面规则：

- 列表显示任务名、成功/失败、结束时间、用时、击毁数、命中率和奖励；点击条目打开详情，详情展示结算文案、射击命中明细和改装快照。
- 支持按任务和成功状态筛选；筛选只影响列表显示，不修改存档，详情返回列表后筛选条件保留。
- “清空战绩”需要二次确认，且只清空 `history`，不影响解锁、资源、改装和设置。
- 没有记录或筛选无结果时显示明确的空状态；所有用户可变文本均通过 `textContent` 渲染。

## 项目结构

```text
index.html
package.json
vite.config.ts
tsconfig.json
src/
  main.ts                  入口
  styles.css               HUD、菜单和结算样式
  core/
    types.ts               向量和通用类型
    history.ts             战绩记录 schema、规范化、追加、筛选
    ship.ts                飞船惯性、资源、部位、碰撞和维修
    weapons.ts             四种武器、过热、弹药和锁定逻辑
    enemies.ts             五种敌人与 AI 状态机
    missions.ts            四关任务条件和胜负判定
    events.ts              动态事件和环境效果
    storage.ts             存档和改装
  game/
    GameApp.ts             输入、游戏流程、HUD、雷达和胜负
    world.ts               Three.js 场景、区域、障碍、敌人、弹道和粒子
    audio.ts               WebAudio 程序化占位音效
tests/
  core.test.ts             Vitest 核心逻辑测试
```

所有模型和材质均由 Three.js 基础几何体与程序化材质生成，音效由 WebAudio 合成，不包含外部商业游戏素材。

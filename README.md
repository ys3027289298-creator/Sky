# 星陨防线（Starfall Defense）

一款原创、可在浏览器中直接运行的 **3D 太空射击游戏**。玩家驾驶轻型战斗飞船穿越陨石带、失控空间站与敌方舰队，连续完成四个任务（侦察 → 护航 → 空间站突袭 → 舰队决战），在有限燃料、弹药、护盾与结构值之间做出取舍。

- 语言：TypeScript（严格模式）
- 构建：Vite 5
- 3D：Three.js（原创几何模型、材质、粒子、雾化与动态光照，无任何外部商业素材）
- 单元测试：Vitest
- 浏览器端到端冒烟测试：Playwright（自动启动 Vite + Chromium）
- 存档：浏览器 `localStorage`，无需后端

## 启动方式

```bash
npm install
npm run dev
```

启动后浏览器会自动打开 `http://localhost:5173`（如未自动打开请手动访问）。进入主菜单后点击「开始任务」即可快速进入第一关，无需注册或登录。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

## 测试方式

```bash
npm test          # Vitest 单元测试（61 个，覆盖核心战斗/任务/存档逻辑）
npm run e2e       # Playwright 真实浏览器冒烟测试（菜单/飞行/射击/暂停/成功与失败结算）
```

> `npm run e2e` 会自动拉起 Vite 开发服务器并用无头 Chromium（SwiftShader 软件渲染）跑完整流程；首次使用需要系统中已安装 Playwright 浏览器（`npx playwright install chromium`）。

## 操作方法

| 按键 | 功能 |
| --- | --- |
| W / S | 加速 / 减速（有惯性与加速上限） |
| A / D | 横向平移 |
| 鼠标移动 | 控制飞船朝向（转向速度受限） |
| Q / E | 侧向翻滚 |
| 鼠标左键 | 主武器射击（持续射击会过热，过热后必须冷却） |
| 鼠标右键 | 按住锁定目标；点击发射副武器 |
| T | 在多个敌人之间切换锁定目标 |
| 1 / 2 | 切换副武器：追踪导弹 / 范围爆破弹 |
| Shift | 加力冲刺（消耗能量与燃料） |
| 空格 | 紧急闪避（消耗能量、有冷却） |
| R | 手动换弹 / 武器冷却 |
| C | 追尾视角 / 驾驶舱视角切换 |
| Y / X / V | 动态事件应对：规避 / 迎战 / 加固（结果不同） |
| Tab | 打开任务与装备信息面板 |
| P / Esc | 暂停（继续 / 重新开始任务 / 返回主菜单） |

游戏中点击画面会锁定鼠标指针；暂停或打开菜单时自动释放。

## 推荐 10–15 分钟演示路线

1. **任务一 · 废弃矿区侦察**：飞至废弃采矿区，依次靠近 3 个蓝色信标完成扫描（注意躲避巡逻侦察无人机），然后返回绿色集结环撤离。
2. **任务二 · 运输船护航**：在陨石带中护送绿色运输船抵达终点，优先击落贴近运输船的截击机与炮艇，运输船血量归零即失败。
3. **任务三 · 失控空间站**：摧毁 3 个红色防御节点 → 拾取青色能源核心 → 在 **35 秒爆炸倒计时**结束前飞到撤离环。
4. **任务四 · 舰队决战**：先关闭两座紫色干扰塔（否则锁定被严重干扰），再集中火力攻击指挥舰的**护盾节点（中部）、炮塔（上部）、引擎（下部）**三个弱点，击毁后立即撤离。

沿途会刷出燃料（蓝）、弹药（黄）、维修包（绿）、升级模块（紫）；绿色光环是**维修点**，消耗能量可完整修复装甲与受损部件。主菜单提供「开始任务」进入单关练习，也可通过完成任务逐关解锁完整战役。

## 主要功能

- **飞船物理**：惯性、阻尼、转向速率、加速限制、加力冲刺、带冷却的闪避位移；升级引擎会真实改变极速与手感。
- **四种武器**：双联能量炮（高射速/过热）、高速脉冲炮（远程高伤）、追踪导弹（锁定后追踪，有限弹药）、范围爆破弹（AOE，有限弹药）；伤害、射速、射程、弹药、冷却各不相同。
- **锁定系统**：锁定锥、锁定进度、目标框、目标距离/护盾/结构显示；距离过远、偏离锁定锥或被陨石/空间站遮挡会脱锁并提示原因；`T` 切换目标；干扰塔/干扰装置会拖慢锁定。
- **防御系统**：结构生命、护盾（脱战缓慢恢复）、装甲（减伤，不自动回满）、能量与燃料；命中不同部位会损坏**引擎（降速）/武器（降射速）/雷达（缩短锁定）**，需用维修包或维修点修复。
- **五种敌人**：侦察无人机、高速截击机、重型炮艇、防御无人机、敌方指挥舰；均有巡逻 → 发现 → 追击 → 攻击 → 搜索/撤退状态机，会避开陨石与大型障碍，看不见玩家（被遮挡或超出侦测范围）时无法开火。指挥舰拥有护盾、弹幕齐射和可破坏的炮塔/引擎/护盾节点弱点。
- **三个区域**：废弃采矿区（陨石带）、失控空间站（掩体 + 爆炸倒计时）、敌方舰队外围（干扰塔 + 指挥舰）；各有独立雾化颜色、密度、光照与环境危险。
- **六种动态事件**：陨石带偏移、敌方增援跃迁、护盾谐波故障、能源站爆炸、运输船改变航线、临时空间风暴。事件先倒计时预警，期间可用 Y/X/V 选择应对，真正改变能见度、护盾、刷怪数量或航线长度。
- **资源与改装**：引擎 / 护盾 / 装甲 / 武器 / 雷达 / 导弹舱六个槽位，每个三级升级，消耗任务获得的改装资源，升级后真实作用于移速、容弹、伤害、锁定距离等实际数值。
- **HUD**：左上任务目标与倒计时、右上雷达与敌机数、中央准星/锁定框/脱锁提示、底部结构/护盾/装甲/能量/燃料条与部件损伤状态、武器过热与副武器弹药、护航血条与空间站爆炸倒计时；受重伤屏幕红边、爆炸震屏。
- **结算**：成功/失败、具体失败原因（如运输船被击毁、未能在爆炸前撤离、结构值归零、超时）、击毁数、命中率、剩余护盾、用时与获得资源；进度、解锁关卡、改装、设置均通过 `localStorage` 持久化。
- **音效**：WebAudio 程序化合成的射击、爆炸、锁定、拾取、警报等占位音效，无外部音频文件。

## 项目结构

```
index.html                  入口 HTML
vite.config.ts              Vite / Vitest 配置
src/
  main.ts                   应用入口：菜单/引擎/HUD/存档串联
  styles.css                全部界面样式
  core/                     与渲染无关、可单测的游戏逻辑
    math.ts                 向量/随机数/视线几何
    types.ts                公共类型
    ship.ts                 飞船物理、惯性、碰撞解算
    defense.ts              护盾/装甲/结构/部位损伤/维修
    weapons.ts              四种武器、过热、弹药、弹丸与追踪
    targeting.ts            锁定、脱锁、目标切换、遮挡判定
    enemies.ts              五种敌人与 AI 状态机、指挥舰弱点
    missions.ts             四个任务的开始/完成/失败/撤离规则
    events.ts               六种动态事件与玩家应对修正
    world.ts                区域、陨石带、拾取物、视线/碰撞查询
    upgrades.ts             六槽位三级改装
    storage.ts              localStorage 存档、迁移与进度更新
  game/
    engine.ts               Three.js 主引擎（更新/渲染/镜头/特效/关卡）
    factory.ts              原创飞船、敌人、陨石、空间站、爆炸粒子模型
    input.ts                键鼠输入与指针锁
    levels.ts               四关的区域、出生点、敌人与物件配置
    audio.ts                WebAudio 程序化音效
  ui/
    hud.ts                  战斗 HUD（含 canvas 雷达）
    menus.ts                主菜单/改装/说明/设置/简报/暂停/结算
tests/                      Vitest 单元测试（8 个文件，61 个用例）
e2e/smoke.mjs               Playwright 浏览器端到端冒烟测试
```

核心战斗逻辑全部放在 `src/core/`，不依赖 Three.js 与 DOM，因此可以在 Node 下被 Vitest 快速测试；`src/game/engine.ts` 负责把核心状态同步到 Three.js 场景并驱动渲染、粒子和镜头。

# 星陨防线

《星陨防线》是一个可直接在浏览器运行的原创 3D 太空射击游戏，使用 TypeScript、Vite、Three.js 和 Vitest 开发。玩家驾驶轻型战斗飞船，在废弃采矿区、失控空间站和敌方舰队外围完成连续任务，管理燃料、弹药、护盾、装甲、能量、维修材料与改装取舍。

## 启动

```powershell
npm install
npm run dev
```

打开终端中显示的本地地址，通常是 `http://localhost:5173/`。无需注册、登录或后端服务。

生产构建：

```powershell
npm run build
npm run preview
```

## 测试

```powershell
npm test
```

测试覆盖：

- 飞船推进、惯性、加速限制、碰撞伤害
- 武器射速、弹药、过热、冷却和命中统计
- 导弹锁定、遮挡脱锁、目标切换
- 护盾、装甲、部位损伤与维修
- 敌人巡逻、发现、追击、攻击、撤退和死亡
- 四个任务的开始、完成、失败和撤离
- 资源拾取、三级改装、localStorage 存档
- 六种动态事件和指挥舰护盾/弱点战斗

## 推荐 10–15 分钟录屏路线

1. 主菜单选择“简单练习”或“完整流程”，第一关飞入左前方废弃采矿区。
2. 靠近扫描区域按 `F`，展示无人机、陨石碰撞和撤离点。
3. 完成第一关后回到主菜单，进入“飞船改装”，升级引擎、护盾或武器。
4. 开始后续任务，途中展示左键主炮过热、右键导弹锁定、补给拾取和维修。
5. 空间站任务摧毁三个防御节点、取得核心，在倒计时结束前撤出。
6. 最终任务关闭两座干扰塔，再攻击指挥舰弱点，最后穿过舰队火力撤离。
7. 可主动撞击陨石或不恢复护盾录制失败页；失败原因会明确显示。

## 任务

1. **废弃采矿区侦察**：进入采矿区、扫描目标、躲避无人机并返航。
2. **陨石带护航**：与运输船路线会合，消灭截击力量，运输船生命归零则失败。
3. **失控空间站突袭**：摧毁三个防御节点，取得能源核心，在爆炸倒计时前撤离。
4. **舰队外围终战**：关闭两座干扰塔，击破带护盾和弱点的指挥舰，在合围前撤离。

## 武器与防御

- **双联能量炮**：均衡主炮，持续射击会过热。
- **高速脉冲炮**：高射速、短射程，适合截击机。
- **追踪导弹**：需要锁定，有限弹药，可被遮挡和距离影响。
- **范围爆破弹**：慢速高伤，适合重型目标和集群。

## 锁定、遮挡与导弹命中判定

目标锁定与导弹命中分**发射时**和**命中时**两个时间点校验，纯逻辑位于 `src/core/combat.ts` 与 `src/core/weapons.ts`，可在 Vitest 中独立运行。

**发射时校验**

- 候选目标必须同时满足可见（未被小行星、空间站等遮挡）且在锁定距离内，缺一不可。
- 当前目标被遮挡或超出距离后，只按 `lostTimer` 降低锁定进度，超过 1.4 秒才清除锁定，期间不会自动切换到其他隐藏候选。
- 请求切换目标时，只允许切换到另一个可见且在范围内的目标。
- 导弹只有在锁定进度满 100% 且持有有效 `targetId` 时才允许发射追踪；主炮和爆破弹保持自由瞄准，不需要锁定。

**命中时校验**

- 导弹命中结算时再次验证目标身份（`targetId`）、存活、射程和当前视线，任一不满足则无伤害，且绝不回退到最近敌人。
- 每次任务开始生成新的 combat/session token，延迟投射物回调必须携带 token；重开任务后旧任务的回调只会被丢弃，不会伤害新局目标。
- 主炮和爆破弹命中时保留原有自由瞄准规则：取指定或最近的存活敌人，要求可见且在射程内。

飞船拥有生命、护盾、装甲、能量、燃料和部位耐久。护盾优先承伤并在脱战后恢复；装甲和引擎、武器、雷达损伤不会完全自愈，需要寻找维修信标或消耗维修包。

## 动态事件

游戏包含陨石带偏移、敌人增援、护盾故障、能源站爆炸、运输船改线和空间风暴。事件有倒计时提示，并实际改变增援、航线、能见度、护盾恢复、能量消耗或战斗压力。

## 存档和改装

游戏使用浏览器 `localStorage` 保存：

- 已解锁任务
- 资源和改装点
- 六类装备的三级升级
- 鼠标灵敏度和音量

改装不是纯数字：引擎影响速度和冲刺，护盾影响护盾量和回复，装甲影响减伤，武器影响伤害和射速，雷达影响锁定距离，导弹舱增加副武器弹药。

## 项目结构

```text
index.html
package.json
vite.config.ts
tsconfig.json
src/
  main.ts                  入口
  styles.css               HUD、菜单和结算样式
  core/
    types.ts               向量和通用类型
    ship.ts                飞船惯性、资源、部位、碰撞和维修
    weapons.ts             四种武器、过热、弹药和锁定逻辑
    combat.ts              导弹发射门槛、命中时再校验和战斗会话 token
    enemies.ts             五种敌人与 AI 状态机
    missions.ts            四关任务条件和胜负判定
    events.ts              动态事件和环境效果
    storage.ts             存档和改装
  game/
    GameApp.ts             输入、游戏流程、HUD、雷达和胜负
    world.ts               Three.js 场景、区域、障碍、敌人、弹道和粒子
    audio.ts               WebAudio 程序化占位音效
tests/
  core.test.ts             Vitest 核心逻辑测试
  combat.test.ts           锁定、遮挡、导弹命中和会话 token 测试
```

所有模型和材质均由 Three.js 基础几何体与程序化材质生成，音效由 WebAudio 合成，不包含外部商业游戏素材。
